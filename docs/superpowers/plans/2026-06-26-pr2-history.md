# 履歴（カレンダー）画面の和モダン化（PR2-B）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 履歴画面（`app/history/page.tsx` ＋ `DiaryCalendar`）を和モダンへ — 明朝＋和風月名の月タイトル、日曜=朱、明朝の大型 streak 数字（🔥絵文字を廃止）、セル角丸調整。

**Architecture:** 和風月名は純関数 `wafuMonthName`（TDD）に集約。`DiaryCalendar` は月タイトルを明朝＋和風月名に、曜日ヘッダと未記入過去の日曜セルを `text-season`（朱）に、セルを `rounded-lg` に。streak は新サーバーコンポーネント `StreakBadge`（lucide Flame ＋ 明朝大型 tabular 数字）に切り出し、`history/page.tsx` の 🔥 絵文字バッジを置換。記入日の若葉ベタ＝データ可視化として据え置き。

**Tech Stack:** Next.js 16 App Router (Server Components), Tailwind v4, lucide-react, vitest, Biome。

## Global Constraints

- 色は必ずトークン（`bg-primary` `text-foreground` `text-muted-foreground` `text-season` `bg-card` / `var(--…)`）。**生hex・任意色・インライン色リテラル禁止**（`npm run lint:design`）。off-token named color も持ち込まない。**絵文字を持ち込まない**（アイコンは lucide）。
- 見出しは `font-heading`（明朝）。font-size/余白/角丸は土台スケールから。11px未満禁止。
- 意味色：若葉(`--primary`)=記入日/streak、朱(`--season`)=日曜（暦）。記入日の若葉ベタは**データ可視化**（憲法の「若葉1〜2箇所」=装飾の話、の例外。メーターと同じ）。新規 drop-shadow 禁止。**ダーク対応必須**。
- スコープは履歴画面のみ。`lib/calendar/month-grid.ts`・`lib/diary/streak.ts`・`components/diary/CalendarDayLink.tsx`（プリフェッチ最適化）は変更しない。分析（PR2-C）に触れない。自動保存/今月の記録カウント等は作らない（YAGNI）。
- 週は日曜始まり7列固定（`buildMonthGrid`）。日曜判定は `grid.weeks.flat().map((cell, index) => …)` の `index % 7 === 0`。`!cell.inMonth`/`isFuture` セルは日曜でも現状の薄色のまま。
- Biome：JS/TS シングルクォート。PRベース運用（main 直push不可、squash merge）。

**作業ブランチ:** 現在の `claude/pr2-history`（最新 main 起点。spec/plan を含む）。1つの PR として squash merge。

- [ ] **Step 2: `cellClasses` に `isSunday` を足し、未記入過去の日曜を朱に・base を rounded-lg に**

`cellClasses` 関数全体を置換:

```tsx
function cellClasses(args: {
  cell: CalendarCell;
  written: boolean;
  isSunday: boolean;
}): string {
  const { cell, written, isSunday } = args;
  const base =
    'aspect-square flex items-center justify-center rounded-lg text-sm';

  if (!cell.inMonth) {
    return `${base} text-muted-foreground/30`;
  }
  if (cell.isFuture) {
    return `${base} text-muted-foreground/50`;
  }
  if (written) {
    const tone =
      'bg-primary text-primary-foreground font-medium hover:opacity-90 transition';
    return cell.isToday
      ? `${base} ${tone} ring-2 ring-foreground/40`
      : `${base} ${tone}`;
  }
  // Past day without an entry (now clickable for backdate)
  if (cell.isToday) {
    return `${base} ring-2 ring-primary text-foreground hover:bg-accent transition`;
  }
  // 未記入・当月・過去・非today。日曜だけ朱。
  return `${base} ${isSunday ? 'text-season' : 'text-muted-foreground'} hover:bg-accent transition`;
}
```

  );
}
